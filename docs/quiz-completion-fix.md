## 复现与原因

以游客身份打开 `/shanhe-weizheng/quiz`，依次选择 15 道题的任意选项，最后点击“看结果”。原页面会显示：

```text
Cannot read properties of undefined (reading 'eventId')
```

构建文件 `assets/index-JcNwwgpo.js` 的 `x1` 组件先取当前题目 `_o[n]`，再读取它的 `eventId`。完成答题时 `n` 等于题目总数 15，数组只有索引 0～14，因此题目不存在。虽然 JSX 有完成页分支，但该分支执行前的档案查找已经抛错。

## 修复

查找关联档案前先判断当前题目是否存在：

```js
c=i?G.find(p=>p.id===i.eventId):void 0
```

没有提前返回组件，因此不改变 React Hooks 的调用顺序。不更改题库、答案、进度、收藏或账号数据。

当前仓库仅提供构建产物，所以对唯一匹配的压缩表达式作最小修正。以后拿到原始源码，应将同等保护迁回答题组件，重新构建；直接覆盖旧产物会丢失此修复。
